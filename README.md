# 🎓 Student Portal

My first programming project, developed in **C** as an introduction to programming fundamentals, memory management and file handling.

The project consists of a prototype **Student Portal**, allowing students and academic information to be managed through a console-based application.

It was developed with a strong focus on understanding fundamental programming concepts, including **pointers, structures, arrays and file handling**.

## 🚀 Features

* Student management
* Curricular unit management
* Student evaluations and grades
* Search and consultation of student information
* Read and write operations with files
* Use of pointers and memory manipulation
* Structured data using C `struct`s
* Console-based interface

## 🛠️ Tech Stack

* **C**
* **File I/O**
* **Pointers**
* **Structs**
* **Arrays**
* **Functions**


## 💾 File Handling

One of the main objectives of the project was learning how to persist information using files.

The application supports reading and writing data to files, allowing information to remain available after the program is closed.

```text
Application
     │
     ├── Write Data ──────► Files
     │
     └── Read Data ◄─────── Files
```

This introduced concepts such as:

* File opening and closing
* Reading data from files
* Writing data to files
* Data persistence
* File modes
* Structured data storage

## 🧠 Pointers & Memory

The project was also used to learn and practice **pointers**, one of the most important concepts in C.

Pointers were used to understand:

* Memory addresses
* References to variables
* Passing data by reference
* Manipulating data through memory addresses
* Working with arrays and structures
* Dynamic memory concepts
